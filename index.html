비정형 텍스트의 정형 엑셀 데이터 변환

고객 의견 메모의 정형 테이블 구조화

편의점 현장에서 수집되는 고객 불편 사항과 제안 메모는 자연어로 작성되어 있어 엑셀 수식이나 피벗 테이블로 직접 집계하기 어렵습니다. 문맥 분석을 통해 비정형 문장을 표준 범주로 분류하고 엑셀 분석이 가능한 정형 테이블로 변환합니다.

첨부된 고객 의견 데이터셋(가상_고객의견_메모.csv)을 분석하여 엑셀에 바로 입력할 수 있는 정형 테이블로 변환하십시오.

[분류 기준]
- 분류 주제: 온도, 대기시간, 상품진열, 결품, 응대태도, 매장청결, 기타 중 가장 적합한 항목 지정
- 고객 감정: 긍정, 부정, 제안 중 하나로 구분
- 실무 조치: 메모의 사실에 근거하여 현업 담당자가 수행할 개선 조치 기술

[출력 규격]
- 탭 구분 텍스트 또는 표 형식으로 출력하십시오.
- 출력 열: 접수번호, 점포명, 접수경로, 원문요약, 분류주제, 고객감정, 실무조치
- 의견 내용이 불분명한 경우 분류 주제를 '기타'로 지정하고 실무 조치에 '추가 확인 필요'로 기술하십시오.
- 개인 식별 정보가 포함된 경우 비식별 처리를 수행하십시오.
- 원천 데이터의 모든 행을 누락 없이 변환하십시오.

대용량 점포 매출 데이터 구조 진단 및 결측치 정제

점포 매출 데이터 무결성 검증 및 이상치 식별

대용량 데이터 집계 전 결측치와 이상치를 사전에 식별하여 데이터 정합성을 확보합니다. 원천 데이터를 임의로 수정하거나 삭제하지 않고 이상 항목의 위치와 특성을 진단합니다.

첨부된 점포 매출 데이터셋(가상_점포별_일별매출.csv)의 데이터 무결성을 검증하고 구조 진단 결과를 제시하십시오.

[진단 요구사항]
- 데이터셋 전체 행 수, 열 목록, 열별 데이터 유형 및 단위를 명시하십시오.
- 고유 점포명 목록, 상권유형 목록, 상품군 목록을 정리하십시오.
- 데이터가 비어 있는 결측 셀의 위치(행 번호 및 열 이름)를 식별하십시오.
- 수치가 0으로 입력된 셀의 위치를 확인하십시오.
- 동일 점포 및 동일 상품군의 일반적 매출 흐름과 비교하여 과도하게 높거나 낮은 이상치를 식별하고 해당 일자, 점포명, 상품군, 매출액을 기술하십시오.

데이터의 임의 수정이나 삭제 없이 식별된 진단 결과만을 객관적인 문장으로 기술하십시오.

조건부 데이터 추출 및 다차원 집계 분석

상권 유형 및 기상 조건 연계 교차 집계

상권 유형과 특정 기상 조건에 따른 상품군별 매출 성과를 다차원으로 집계하고, 원천 엑셀 데이터의 합계 수치와 정합성을 대조 검증합니다.

가상_점포별_일별매출.csv 데이터를 기반으로 조건부 다차원 매출 집계를 수행하십시오.

[처리 규칙]
- 결측치가 포함된 셀은 해당 집계에서 제외하되 행 전체는 삭제하지 마십시오.
- 이상치 데이터는 원값을 유지하여 계산하고 하단에 별도 주석으로 표기하십시오.

[산출 집계표]
- 점포별 총 매출액 합계 및 총 판매건수 합계 테이블 (매출액 기준 내림차순 정렬, 천 단위 쉼표 표기)
- 최고기온 30도 이상 조건 하의 점포별 음료 상품군 매출 합계 및 발생 일수 테이블

[정합성 검증]
- 집계 결과 하단에 전체 데이터의 총 매출액 합산 금액을 명시하여 엑셀 원천 데이터와 교차 대조할 수 있도록 하십시오.

시계열 데이터 시각화 및 공공 통계 비교 분석

일별 매출 변동 차트 및 공공 유통 동향 대조

점포별 일별 매출 변동 추이를 시각화하여 시계열 패턴을 분석하고, 공공데이터포털의 유통 통계와 연계하여 거시적 업태 성장률과 점포 실적을 대조합니다.

가상_점포별_일별매출.csv 데이터와 공공데이터(D1_원본.csv)를 연계 분석하여 시각화 차트와 거시 동향 비교 결과를 도출하십시오.

[요구사항]
- 가상_점포별_일별매출.csv 데이터를 바탕으로 일자별 총 매출액 변동 추이를 다중 꺾은선 차트로 시각화하십시오. (가로축: 일자, 세로축: 일별 총 매출액, 범례: 점포별 구분)
- 점포별 최고 매출 달성일과 최저 매출 달성일을 해당 수치와 함께 정리하십시오.
- D1_원본.csv의 '편의점_총계' 열을 참조하여 월별 전년 동월 대비 매출 증가율 추이를 정리하고 최고 성장률 및 최저 성장률 기록 시점을 명시하십시오.
- 원천 데이터에 명시되지 않은 외부 요인은 자의적으로 해석하지 마십시오.

엑셀 업무 자동화 매크로 구현

폐기율 산출 및 기준 초과 데이터 자동 분리

반복되는 주간 발주 및 재고 데이터 검토 업무를 자동화하기 위해 엑셀 VBA 코드를 작성하여 폐기율 자동 계산 및 특정 기준 초과 항목 분리를 구현합니다.

엑셀 파일 가상_상품군별_주간_발주재고.xlsx의 '발주재고' 시트 데이터를 처리하는 완성형 VBA 매크로 코드를 작성하십시오.

[시트 환경]
- 시트명: 발주재고
- 열 구성: A열 주차, B열 점포명, C열 상품군, D열 발주수량, E열 판매수량, F열 재고수량, G열 폐기수량

[매크로 수행 요구사항]
- 프로시저 명칭: Sub 폐기율점검()
- H열 1행에 '폐기율' 열 헤더를 생성하십시오.
- 2행부터 마지막 데이터 행까지 폐기수량 / 발주수량을 계산하여 H열에 백분율(소수 둘째 자리)로 입력하십시오.
- 발주수량이 0이거나 빈 셀인 경우 계산 오류를 방지하기 위해 '확인 필요' 텍스트를 입력하십시오.
- 폐기율이 5%(0.05)를 초과하는 데이터 행 전체를 '폐기율5퍼센트초과' 워크시트로 자동 복사하십시오. (기존 동일 시트 존재 시 초기화 후 생성)
- 작업 완료 후 추출된 총 행 수를 메시지 창(MsgBox)으로 안내하십시오.

각 실행 블록의 기능을 설명하는 한글 주석을 포함하십시오.

엑셀 고급 수식 기반 대체 자동화

동적 배열 함수 기반 데이터 필터링

매크로 사용이 제한된 보안 환경에서도 동일한 업무를 수행할 수 있도록 표준 함수 및 동적 배열 함수를 활용한 수식 체계를 구성합니다.

가상_상품군별_주간_발주재고.xlsx 파일을 대상으로 매크로 없이 엑셀 수식만으로 데이터를 처리하는 수식 체계를 작성하십시오.

[수식 구성 요구사항]
- H2 셀 적용 폐기율 산출 수식: 발주수량(D열)이 0이거나 빈 셀이면 '확인 필요'를 표기하고 정상 수치이면 폐기수량 / 발주수량 계산
- FILTER 함수 활용 동적 추출 수식: H열의 폐기율이 0.05를 초과하는 데이터 전체를 별도 영역으로 자동 추출
- 구버전 엑셀 호환 수식: FILTER 함수 미지원 환경을 위한 IF, INDEX, MATCH 결합 수식

각 수식의 적용 위치와 함수별 인수 구성을 개조식 문장으로 기술하십시오.
